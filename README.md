# black-window-emulator
Black Window Emulator v1.1 is a 100% non-root Windows &amp; console gaming emulator for Android. Built with a pure black UI, it supports Box64/FEX translation, automatic Snapdragon (Turnip) &amp; MediaTek (Vortek) GPU drivers, GameHub &amp; Windows 11 desktop modes, async shader cache, virtual swap RAM, and AMD FSR upscaling. Build instantly via GitHub Actions
